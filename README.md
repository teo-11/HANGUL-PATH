# Hangul Path — Korean Study App

A responsive, static Korean-learning web app in Russian, English, and Ukrainian.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (or upload all files from this folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and copy the URL it shows.

## Included
- 8 beginner A1 lessons: Hangul, introductions, particles, present/past tense, place particles.
- Korean examples with romanization and Ukrainian translations.
- Russian / English / Ukrainian interface.
- Multiple-choice lesson checks.
- Completion status and progress stored in browser localStorage.

## Important
This is a starter A1 curriculum, not a million-word dictionary or a complete TOPIK course. Progress is stored in the current browser/device; it does not sync between devices. For university admission, verify each university's current language and TOPIK requirements.
